# Beschriftung: Zelldifferenzierung

**Abbildung 01: Zelldifferenzierung**

Die Beschriftungen der Zellzeichnungen sind nach ihrer Position im Bild geordnet.

| Position im Bild | Beschriftung |
|---|---|
| Oben links | Drüsenzelle |
| Oben, links der Mitte (stark verzweigte Zelle) | Nervenzelle |
| Oben, Mitte (Zellverband) | Stammzellen (8-zelliger Embryo) |
| Oben rechts (zwei Zellen) | Blutzellen |
| Unten links | Knorpelzelle |
| Unten, Mitte (lang gestreckte Zelle) | Muskelzelle |
| Unten, rechts der Mitte (Zelle mit Geißel) | Spermienzelle |
| Unten rechts (große runde Zelle) | Eizelle |

**Original-Bildunterschrift:** 01 Zelldifferenzierung
